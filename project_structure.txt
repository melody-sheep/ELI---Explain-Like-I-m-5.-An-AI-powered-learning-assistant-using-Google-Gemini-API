KEY FEATURES:

AI Services:
  ├── Google Gemini API (primary)
  ├── DeepSeek API (fallback)
  └── Mock AI mode (offline testing)

Request Types:
  ├── /ask              → General questions
  ├── /summarize        → Summarize text
  ├── /eli5             → Explain simply (like you're 5)
  └── /code             → Code explanations

Database Models:
  ├── Users             → Application users
  ├── Conversations     → Chat history
  ├── Projects          → User projects
  └── Attachments       → File uploads

═══════════════════════════════════════════════════════════════════

TECHNOLOGY STACK:

Backend:         Laravel 13 (PHP 8.3+)
Database:        MySQL
Frontend:        Blade Templates + JavaScript
Styling:         Tailwind CSS
Bundler:         Vite
Testing:         PHPUnit
Session:         Database-based

═══════════════════════════════════════════════════════════════════

QUICK COMMANDS:

Setup:
  composer install                 # Install PHP dependencies
  npm install                      # Install Node dependencies
  cp .env.example .env             # Setup environment
  php artisan key:generate         # Generate app key
  php artisan migrate              # Run migrations
  php artisan db:seed              # Seed database

Development:
  php artisan serve                # Start development server
  npm run dev                       # Start Vite dev server
  php artisan test                 # Run tests
  php artisan tinker               # Interactive shell

═══════════════════════════════════════════════════════════════════

API ENDPOINTS:

POST   /ask                 → Ask a question
POST   /summarize           → Summarize text
POST   /eli5                → Explain like I'm 5
POST   /code                → Explain code
POST   /explain-code        → Explain code (alias)
GET    /history             → Get conversation history
DELETE /history/{id}        → Delete conversation entry
